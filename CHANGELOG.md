# Change Log

All notable changes to the "kube-localization-helper" extension will be documented in this file.

## [0.0.2]

- CI check for version increment on pull requests.
- Updated GitHub Actions workflows to Node.js 22 and 24.
- Linter rule fixes and updated style guidelines.
- Added localized documentation and contribution guides (`README.md`, `README.ja.md`, `README.ko.md`, `CONTRIBUTING.md`).

## [0.0.1]

- Initial release (`init`).
- Interactive glossary hover provider for Kubernetes documentation terminology.
- Dotted-underline text decorations for recognized terms in Markdown files.
- Japanese (`ja`) and Korean (`ko`) glossary databases.
- Japanese style linter (Tier 1 mechanical rules and Tier 2 heuristic rules).
